## Stable interface
Module COMMANDS maps command name to callable(argv). xsv_core exports Error; parse(args,value_options=(),flag_options=(),defaults=None,aliases=None)->opts,pos; read_csv(path=None,opts=None,flexible=False)->headers,rows; write_csv(headers,rows,opts=None); select_indices(selection,headers,width=None). None headers means -n. Options underscore-normalized. Input paths None/'-' mean stdin. Output defaults comma independently of input delimiter. Optional aliases overrides command-local short options without mutating global defaults.
